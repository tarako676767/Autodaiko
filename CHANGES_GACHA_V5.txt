Tsum Gacha v5 changes
=====================

1. Pickup maxcnt handling fixed
- maxcnt is treated as successful purchase/draw count, not HTTP call count.
- retcode=0 with no coin/ticket decrease is logged as NO-PROGRESS and does not increment draws.
- A single no-op response is tolerated; 3 consecutive no-progress responses stop safely.
- Pickup call ceiling uses maxcnt + 10 slack (capped by TSUM_GACHA_MAX_CALLS).

2. Insufficient funds are non-fatal
- Coin/ruby/medal shortage is shown as a warning/unfinished stop instead of a technical failure.
- Discord result title becomes "処理完了（一部未完了）" when only warnings occurred.

3. Existing native-aligned logic retained
- Pickup uses /pickUpResult.nhn.
- Premium+ uses medal/ticket payment, current GachaBonusInfo.id and Single/Multi selection.
- Authentication/SecureSession/coin/player-level logic unchanged.
