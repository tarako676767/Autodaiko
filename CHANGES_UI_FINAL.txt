Tsum UI / Result Polish Final

表示のみを中心に調整。通信・認証・ガチャAPIロジックはV5を維持。

- 「プレボ完売」→「プレミアムBOX完売」に名称統一
- 既に完売しているBOXは「現在は完売しています」と表示
- 内部gachaid/callsなどの開発向け情報をユーザー向け結果から削減
- 完売成功時は「完売しました（処理 N回）」と表示
- 代行終了後に最新残高を再取得
- コイン増加時: 増加コイン +N / 現在 N
- コイン消費時: 消費コイン N / 現在 N
- Premium+では現在メダルも表示
- メダル消費時: 消費メダル N / 現在 N
- ルビーに変動があった場合のみ変動を表示
- 資源不足はエラーではなく「一部未完了」として見やすく表示
- 資源不足時は現在残高 / 次回必要数 / 処理済み回数を改行表示
- タイトル「処理完了（一部未完了）」→「代行完了（一部未完了）」
